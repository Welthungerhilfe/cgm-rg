# Security Policy

## 📣 Reporting a Vulnerability

If you discover a security vulnerability in this repository, **please do not create a public issue**.

Instead, please **responsibly disclose** it by emailing us at:

**security@childgrowthmonitor.org**

---

## 🔒 Supported Versions

We generally provide security updates for:

- The latest stable release
- Any active long-term support (LTS) branches

Older versions may not receive security fixes. Please check our [RELEASE.md](./RELEASE.md) or documentation for details.

---

## ✅ Our Commitments

- We will acknowledge receipt of your report within **[e.g., 2 business days]**.
- We will investigate and validate the issue promptly.
- We will work to fix confirmed vulnerabilities as soon as possible.
- We will credit reporters in our release notes or advisories (if desired).

---

## ⚠️ Scope

This policy applies **only** to security issues in this repository's code and related infrastructure.

Please do **not** use this process for:

- General bugs or feature requests (use Issues or Discussions instead).
- Social engineering or phishing attacks against our team.
- Denial-of-service attacks not related to specific code vulnerabilities.

---

## 🤝 Thanks

We appreciate responsible security research and disclosure to help keep our project and users safe.
